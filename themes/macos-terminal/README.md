# macOS Terminal Ayu Mirage Theme

## Installation

1. Download the `Ayu-Mirage.terminal` file
2. Double-click the file to open it in Terminal.app
3. Terminal will automatically import the theme
4. Go to Terminal > Preferences > Profiles
5. Select "Ayu Mirage" and click "Default" to make it your default theme

## Alternative Installation

1. Open Terminal.app
2. Go to Terminal > Preferences (Cmd+,)
3. Click the Profiles tab
4. Click the gear icon at the bottom left
5. Select "Import..."
6. Choose the `Ayu-Mirage.terminal` file

## Features

- Dark background (#1F2430) 
- Bright foreground text (#CBCCC6)
- Golden cursor (#FFCC66)
- Optimized ANSI colors for readability
- Perfect for long coding sessions
